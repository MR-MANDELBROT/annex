Datenschutz

aOS hat keinen Server und sammelt nichts.

aOS läuft auf deinem Mac und deinem iPhone. Hier steht alles, was es schickt, speichert und sieht.

  • Keine Statistiken

    aOS schickt keine Statistiken, Absturzberichte oder Nutzungsdaten irgendwohin. Ein Konto brauchst du nicht.

  • Downloads

    aOS lädt macOS von Apple, Google Chrome von Google (im Arbeitsplatz) und seine eigenen Updates über den Feed dieser Website auf GitHub. Diese Server sehen eine normale Download-Anfrage.

  • Die Zugangsdaten deines Agents

    aOS liest, speichert und leitet nie Zugangsdaten deiner Agents oder Konten weiter. Die Anmeldung bei einem Agent läuft immer über dessen eigenen Weg.

  • Anmeldungen, die du freigibst

    Gibst du eine Anmeldung frei, geht sie einmal von deinem iPhone oder Mac über SSH zum Arbeitsplatz und wird in genau diese Website eingetragen. aOS behält sie nicht.

  • Bitwarden

    Nutzt du Bitwarden, bleiben deine Passwörter in deinem Bitwarden-Konto. aOS nutzt eines nur, wenn du es freigibst, für genau diese Anmeldung.

  • Auf deinem Mac

    Alles, was aOS speichert, bleibt auf deinem Mac, in ~/Library/Application Support/aOS: der Arbeitsplatz, seine Schlüssel, Protokolle und der Austauschordner. Löschst du den Ordner, ist alles weg.

  • aOS für iPhone

    Die iPhone-App spricht direkt über SSH mit deinem Mac, mit einem Schlüssel, der das iPhone nie verlässt. Dazwischen gibt es keinen Server und kein Konto von uns.

  • Mitteilungen

    Mitteilungen zu Anfragen kommen über Apple auf dein iPhone. Sie nennen den Agent und den Grund, nie ein Passwort.

  • Was dein Agent sieht

    Dein Agent sieht Bildschirmfotos des Arbeitsplatzes, während er arbeitet. Was damit passiert, regeln der Anbieter deines Agents und seine Bedingungen.

  • Diese Website

    Diese Website liegt bei GitHub Pages, und GitHub verarbeitet deine IP-Adresse, um sie auszuliefern. Die Website selbst setzt keine Cookies und lädt keine Tracker oder fremden Schriften.
