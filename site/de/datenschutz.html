Datenschutz

Annex hat keinen Server und sammelt nichts.

  • Annex schickt keine Statistiken, Absturzberichte oder Nutzungsdaten irgendwohin.
  • Es lädt macOS von Apple, Google Chrome von Google (im Arbeitsplatz) und seine eigenen Updates über den Feed dieser Website. Diese Server sehen eine normale Download-Anfrage.
  • Es liest, speichert und leitet nie Zugangsdaten deiner Agents oder Konten weiter. Die Anmeldung bei einem Agent läuft immer über dessen eigenen Weg.
  • Alles, was Annex speichert, bleibt auf deinem Mac, in ~/Library/Application Support/Annex: der Arbeitsplatz, seine Schlüssel, Protokolle und der Austauschordner. Löschst du den Ordner, ist alles weg.
  • Dein Agent sieht Bildschirmfotos des Arbeitsplatzes, während er arbeitet. Was damit passiert, regeln der Anbieter deines Agents und seine Bedingungen.
